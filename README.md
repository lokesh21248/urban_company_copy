# Urban Company Copy - Admin Portal

Modern React + TypeScript admin portal for managing categories, subcategories, services, bookings, providers, and banners.

## Tech Stack
- **React 18** + **TypeScript** + **Vite**
- **Tailwind CSS** for styling
- **TanStack React Query** for server state management
- **Axios** for API communication
- **Lucide React** for modern icons

## Features
- **Categories & Services Management**: Add, view, edit, and delete categories, subcategories, and individual service items.
- **Image Upload Integration**: Upload icons, promotional service images, and wide banners directly to backend storage.
- **Banners Management**: Manage dynamic promotional banners and links.
- **Provider & Customer Management**: View and monitor service providers and users.
- **Real-time Bookings Dashboard**: Track incoming and historical booking requests.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
